## 📖 Overview

**CapacityConnect** is a competency-driven learning, evaluation, and credentialing ecosystem designed specifically for the **India Meteorological Department (IMD)** and **Ministry of Earth Sciences (MoES)**. It transitions institutional capacity building from fragmented spreadsheets, WhatsApp groups, and manual registers into a centralized, auditable digital platform.

### Core Capabilities

1. **Centralized Learning**: Unifies training sessions, resources, assignments, assessments, and communication across all IMD Regional Meteorological Centers.
2. **Competency Gap Analysis**: Compares required competencies with existing skill levels to identify targeted areas needing development.
3. **Smart Trainer Matching**: Matches training requirements with qualified trainers based on domain expertise, qualification, experience, and availability using AI vector embeddings.
4. **Unified Progress Tracking**: Real-time telemetry on participation, assessment results, and competency progress across operational shifts.
5. **Data-Driven Administration**: Centralized executive dashboards for national workforce readiness, role approvals, and emergency deployment analytics.

## 🛠️ Tech Stack

* **Frontend**: React 18, Vite, Tailwind CSS, Lucide React, Recharts
* **Backend API**: Python, FastAPI, Pydantic, AsyncIO
* **Database**: PostgreSQL with SQLAlchemy ORM & Alembic migrations
* **AI Matching**: Sentence Transformers (`all-MiniLM-L6-v2`) & `pgvector` Cosine Similarity
* **Deployment**: Vercel Edge Network

## 💻 Local Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/varshanalpha/Team-Website.git
   cd Team-Website
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
